# Nevcihan
Nevcihan, modern web teknolojileri ile 3 boyutlu etkileşimi bir araya getiren; kullanıcıların web üzerinde akıcı bir 3D sahne deneyimi yaşamasını sağlayan ve yapay zekâ destekli rehber/asistan bileşenleriyle zenginleştirilmiş yeni nesil bir web platformudur.

🌟 Öne Çıkan Özellikler
Etkileşimli 3D Deneyimi: Spline entegrasyonu ile web ortamında optimize edilmiş, doğrudan etkileşime girilebilen 3D sahneler.

Yapay Zekâ Navigasyon Desteği: Kullanıcıyı yönlendiren, bağlamsal etkileşim sunan akıllı rehber arayüzü.

Hızlı ve Modüler Mimari: Vite ve modern React mimarisiyle minimum yükleme süreleri ve yüksek performans.

Duyarlı (Responsive) Tasarım: Masaüstü ve mobil ekranlarda dengeli görsel hiyerarşi ve kontrol mekanizması.

🛠️ Teknolojiler
Frontend: React, Vite, JavaScript (ES6+), CSS3 / SCSS

3D & Grafik: Spline (@splinetool/react-spline)

Yapay Zekâ Entegrasyonu: AI Assistant / Contextual Navigation API

Versiyon Kontrol: Git & GitHub
